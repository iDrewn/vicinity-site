# VIcinity

Website for **VIcinity**, a community chart, cheat list, guide library and progress tracker for open-world games on iPhone and iPhone Duo (iOS 26 and later).

Live site: https://idrewn.github.io/vicinity-site/

- [Home](https://idrewn.github.io/vicinity-site/)
- [Privacy policy](https://idrewn.github.io/vicinity-site/privacy.html) · [Integritetspolicy](https://idrewn.github.io/vicinity-site/integritet.html)
- [Support](https://idrewn.github.io/vicinity-site/support.html)

The site is plain HTML and CSS, published with GitHub Pages from the `main` branch. Report problems or ideas for the app through this repository's issues. The app itself lives in a separate private repository.
